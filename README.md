# Netflix Dashboard – Power BI

## Project Overview
This project presents a Netflix data visualization dashboard developed using Microsoft Power BI. It focuses on presenting data through an interactive and visually organized dashboard.

## Tools & Technologies
- Microsoft Power BI
- Data Visualization
- Dashboard Design

## Project Objectives
- Present Netflix-related data in a visual format.
- Design an organized and interactive dashboard.
- Make information easier to explore and understand.

## Project File
The Power BI dashboard file is available in this repository:

`pbinetflix.pbix`

Download the file and open it using Microsoft Power BI Desktop.
